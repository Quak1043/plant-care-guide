水生植物造景近年来越来越受欢迎，一缸睡莲、一丛铜钱草、几尾小鱼……打造一个生机勃勃的小水景，给家居增添灵动的气息。

一、适合家庭种植的水生植物

浮水植物（叶片浮在水面）：

  • 睡莲：花大色艳，是水生花卉的代表
  • 碗莲：小型荷花，适合盆缸种植
  • 浮萍：繁殖迅速，能净化水质
  • 荇菜：叶片如睡莲，花黄色，诗经中的"参差荇菜"

挺水植物（根在水底，茎叶挺出水面）：

  • 铜钱草：叶片圆圆如铜钱，生长迅速
  • 水生鸢尾：花型美丽，适合水边种植
  • 再力花：高大挺拔，花紫色，很有气质
  • 梭鱼草：穗状蓝花，清新雅致

沉水植物（整株在水下）：

  • 金鱼藻：能净化水质，适合养鱼的缸
  • 水榕：水草缸常见，叶片坚韧

二、容器选择

水生植物的容器选择取决于你想种什么和放在哪里：

  • 小型桌面：玻璃碗、陶瓷碗、金鱼缸（适合铜钱草、碗莲小型品种）
  • 中型阳台：荷花缸、陶缸、塑料大盆（适合睡莲、中型碗莲）
  • 大型庭院：水池、池塘（各种水生植物都可以）

注意事项：

  • 容器深度至少20cm以上，睡莲需要更深
  • 不漏水是基本要求
  • 陶瓷缸和陶缸比塑料缸更有质感
  • 放在阳光充足的地方，大多数水生植物喜阳

三、种植方法

睡莲种植方法：

  1. 在缸底铺15-20cm厚的塘泥或肥沃的园土
  2. 将睡莲藕根或种球埋入土中，芽点朝上
  3. 轻轻覆土，不要埋太深
  4. 缓慢加水，先加少量水，待土沉淀后再加满
  5. 放在阳光充足的地方

铜钱草半水半土种植：

  1. 在容器底部铺5-10cm厚的土
  2. 将铜钱草种在土中
  3. 加水至土面以上2-3cm
  4. 放在阳光充足处，很快就会爆盆

碗莲种植：

  1. 碗莲种子破壳（凹进去的那头）
  2. 温水浸泡催芽，每天换水
  3. 出芽后长到2-3片叶时定植
  4. 定植在塘泥中，加水养护

四、日常养护

光照：大多数水生植物喜阳，每天至少4-6小时直射光才能生长良好、开花繁茂。光照不足会徒长、不开花。

水质：定期换水保持水质清洁。夏季高温时水分蒸发快，要及时补水。长绿藻是正常现象，不严重时不用管。

施肥：水生植物也需要施肥，可以使用水生植物专用缓释肥，埋入土中。不要直接把肥料撒在水里，会导致藻类爆发。

越冬：耐寒品种（如睡莲、荷花）可以在室外越冬，保持水面不结冰即可。热带品种冬季需移至室内。

五、养鱼+养植物：打造小生态

在水缸里养鱼+养水生植物，可以形成一个小型生态系统：鱼的粪便为植物提供养分，植物净化水质，鱼吃蚊虫幼虫。

适合的鱼：

  • 小型鱼：斑马鱼、孔雀鱼、灯鱼
  • 冷水鱼：金鱼、锦鲤（需要较大空间）
  • 食蚊鱼：吃蚊子幼虫，适合室外

注意事项：

  • 容器不能太小，鱼需要足够的活动空间
  • 不要养太多鱼，密度要适中
  • 养鱼的缸不要频繁换水，保持水质稳定
  • 可以加一个小型过滤器或增氧泵
